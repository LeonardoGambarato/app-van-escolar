# 🚐 App Van Escolar

Sistema de gerenciamento de transporte escolar desenvolvido com Java + Spring Boot.

## 📌 Funcionalidades

* Cadastro de alunos
* Cadastro de motoristas
* Login de usuários
* Dashboard administrativo
* Controle financeiro
* Gestão de rotas

## 🛠 Tecnologias

* Java 21
* Spring Boot
* Spring Data JPA
* Maven
* PostgreSQL
* HTML / CSS / JavaScript

## ▶ Como executar

```bash
git clone https://github.com/LeonardoGambarato/app-van-escolar.git
```

Configure o banco no `application.properties`.

Execute:

```bash
mvn spring-boot:run
```
